# ⚾ メジャー監督（仮の名前）

> 書いた人: AI（Claude）。ゲームの名前「メジャー監督」は仮（AI）。決まったことは [決まったこと.md](決まったこと.md)。

ペナント監督（`C:\Users\asato\Desktop\game\baseball`）をもとにした、メジャーリーグ版の新しいゲームです。
30 球団（ネーショナル・リーグとエメリケン・リーグ、各 3 地区）の 1 球団を率いて、育てて、稼いで、ユニバースシリーズ制覇を目指します。
HTML / CSS / JavaScript だけで動きます。

## 遊び方

```powershell
python -m http.server 8794 --bind 127.0.0.1
```

ブラウザで http://127.0.0.1:8794/ を開きます。

## できること（最初の版）

- **日程**：162 試合（81・40 も選べる）。同じ地区 13×4・同じリーグの別の地区 6〜7×10・ライバル 4・別のリーグ 3×14。月曜休みはなく、カードの合間に休み。7 月にオールスター（1 試合）とドラフト
- **枠**：26 人枠（9 月から 28 人）・40 人枠・マイナー契約（3A・2A・1A）。オプション（3 シーズン）・DFA とウェーバー・負傷者リスト（10/15 日と 60 日）
- **ポストシーズン**：各リーグ 6 球団。ワイルドカードシリーズ → 地区シリーズ → リーグ優勝決定シリーズ → ユニバースシリーズ。引き分けなし
- **お金**：万ドル。市場の大・中・小、全国の放映権、収入の分け合い、段のあるぜいたく税
- **契約**：サービスタイム（172 日で 1 年）。調停前・年俸調停（スーパー 2・ノンテンダー）・FA（QO と補償の指名権）。契約は最大 10 年
- **ドラフト**：7 月。ロッタリー（上位 6 番）、10 巡目まで、契約金の枠。高校生は断って大学へ進むことがある
- **オフ**：表彰 → QO・FA → ノンテンダー → ルール 5 → 年俸調停 → 国際アマ（16 歳）・アジアのプロからのポスティング → スプリングトレーニング

## ファイル

| ファイル | 中身 |
|---|---|
| `js/data.js` | 名前・球団・数値（数値はすべて仮・AI） |
| `js/player.js` | 選手の作成・評価・成長 |
| `js/sim.js` | 試合のシミュレーション（元のまま。延長は決着まで） |
| `js/league.js` | 日程・枠・経営・ポストシーズン・オフ・ドラフト・保存 |
| `js/ui.js` | 各画面の描画 |
| `js/main.js` | ボタン操作 |

セーブのキーは `mlbm_save_v1`、オフライン用の取っておく分は `mlbm-` で始まる名前にしたので、同じサイトに置いてもペナント監督のセーブとは混ざりません。
